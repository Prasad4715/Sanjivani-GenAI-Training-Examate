
# ChalanCheck – Resume Highlights

**Project:** ChalanCheck – AI-Powered Traffic Challan Assistant

**Tech Stack:** Python, FastAPI, Streamlit, Google Gemini, RAG, ChromaDB, Sentence Transformers, LangGraph, Docker, GitHub Actions, Render

## Resume Bullet Points

- Developed an AI-powered traffic challan assistant using FastAPI, Streamlit, and Google Gemini to explain Indian traffic violations, penalties, and legal consequences in simple language.

- Implemented a Retrieval-Augmented Generation (RAG) pipeline using Sentence Transformers and ChromaDB, indexing 1,726 legal document chunks from four legal PDFs to generate evidence-grounded answers with source citations.

- Built LangGraph agent workflows with tool execution and approval handling, added response caching, token and latency monitoring, and input validation, and deployed the application on Render using Docker and GitHub Actions CI/CD.
